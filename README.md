# Shop Bakery — Modern Bakery Landing Page

Responsive multi-section landing page for a modern artisan bakery, developed from a Figma design using semantic HTML5, SASS/SCSS, and JavaScript.

🔗 **[Live Demo] (https://maya28may.github.io/modern-bakery-landing/)**

## 🛠 Tech Stack
- **HTML5:** Semantic markup
- **CSS3 / SCSS:** Flexbox, Grid, responsive layout, custom variables & mixins
- **Methodology:** BEM (Block Element Modifier)
- **JavaScript (ES6+):** Interactive modal windows, mobile navigation menu, and slider functionality
- **Tools:** Git, GitHub, Prettier, Figma

## ✨ Key Features
- Fully responsive layout adapted for mobile, tablet, and desktop screens
- Interactive mobile burger menu and callback modal window
- Custom slider/carousel for product formats
- Cross-browser compatibility and optimized SVG icons
